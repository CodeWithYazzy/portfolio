Neural Network Playground

A two-input network learns to separate two classes. The background is its current prediction; the markers are the training data.

Epoch 0 · Loss 0.69 · Accuracy 50%

A 2→H→1 network with tanh hidden units and a sigmoid output, trained by full-batch gradient descent to minimize binary cross-entropy. More hidden units add capacity; more label noise makes the boundary less certain.

Gradient Descent Simulator

Gradient descent updates a point by moving it against the slope. Watch it settle into a minimum, or overshoot.

x ← x − η f′(x)
Loss surface Current point · tangent · path

x = −2.00 · f(x) = 8.54 · slope = −4.76 · Step 0

The update rule is x ← x − learning rate × f′(x). The bowl has one minimum. The double well has two, so the starting point matters; start at zero and the point sits on the hilltop. When the learning rate is too high, it can overshoot or diverge.

K-Means Clustering

K-means alternates between assigning points to the nearest centroid and moving each centroid to the center of its group.

Lloyd iterations
Cluster assignments Markers show cluster membership

Iteration 0 · Inertia 0.0 · 3 clusters

Each step assigns every point to its nearest centroid, then moves each centroid to the mean of its points. Inertia is the sum of squared distances to the nearest centroid; lower is tighter. K-means finds geometric groups, not meaning.
