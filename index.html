MOST DETAILED

Iris Flower Classifier
End-to-end tabular pipeline — from raw measurements to deployed inference.

A complete classification system built to demonstrate rigorous ML engineering: stratified splits, preprocessing pipelines, cross-validated model comparison, and held-out evaluation — not a notebook-only demo.

ProblemClassify iris species from 4 numeric measurements.
ArchitectureSingle-stage scikit-learn pipeline (Scaler + Classifier).
DataIris — 150 samples, 4 features, 3 classes. 80/20 stratified split.
TrainingStandardScaler fit on train only; cross-validated model comparison.
Metrics — held-out test
